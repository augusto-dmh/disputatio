## Provenance policy

- Self-authored skills tie to an ADR or a documented process doc (`docs/PROCESS.md`).
- Vendor/official skills, if ever vendored, are hash-pinned in a `skills-lock.json` (learny's pattern) — none today.
- No third-party blog-quality skills: each skill is reviewed like code, because it *is* process code.
